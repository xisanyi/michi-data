# michi-data

Regional data packages for the ErreichbarkeitsAtlas desktop app
(Valhalla routing tiles + POI SQLite indexes per German state).

- `data/catalog.json` — package catalog fetched by the desktop app
- `data/coverage/` — per-package coverage polygons (GeoJSON)
- Releases — versioned zip archives (`data-YYYY.MM.DD` tags)
